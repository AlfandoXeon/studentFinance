Aplikasi Desktop Pencatat Keuangan Pribadi untuk Mahasiswa

Student Finance dirancang untuk membantu mahasiswa mengatur uang saku, memantau pengeluaran harian, dan merencanakan anggaran bulanan secara tertib. Bekerja 100% offline dengan database lokal SQLite untuk menjamin privasi finansial sepenuhnya di komputer Anda.

100% Offline-First Data tersimpan lokal di SQLite.

Kapabilitas Sistem

Fitur Utama Aplikasi

Fasilitas yang disediakan untuk mendukung kedisiplinan finansial sehari-hari.

01.

Dashboard & Multi-Akun

Pantau saldo konsolidasi dari seluruh dompet fisik (kas tunai), rekening bank, serta akun dompet digital (e-wallet) dalam mata uang Rupiah (IDR). Dilengkapi ringkasan arus kas masuk dan keluar bulanan.

02.

Student Survival Mode

Perhitungan jatah belanja harian yang aman berdasarkan sisa uang tunai yang tersedia setelah dipotong kewajiban tertunda (seperti uang kos atau tagihan) dibagi dengan sisa hari hingga tanggal kiriman berikutnya.

03.

Pencatatan Transaksi & Transfer

Pencatatan pemasukan, pengeluaran, dan transfer saldo antar-rekening dengan validasi ketat. Mutasi transfer dicatat secara atomik tanpa mendistorsi laporan arus kas bersih konsolidasian.

04.

Batas Anggaran (Budget Cap)

Atur pagu anggaran per kategori belanja (misal: Makanan, Transportasi, Hiburan). Sistem memberikan peringatan visual ketika pengeluaran suatu kategori telah menyentuh ambang 80% dari batas pagu.

05.

Laporan Keuangan & Ekspor CSV

Filter transaksi berdasarkan rentang tanggal dan kategori. Pengguna dapat mengekspor data ke format berkas CSV standar untuk kebutuhan dokumentasi atau analisis lanjutan di spreadsheet.

06.

Pencadangan Data (Backup & Restore)

Fasilitas pencadangan database lokal ke berkas cadangan dengan satu klik, lengkap dengan mekanisme verifikasi integritas file sebelum pemulihan data dilakukan.

Informasi Tambahan

Pertanyaan yang Sering Diajukan

Apakah aplikasi ini membutuhkan koneksi internet?

Tidak. Student Finance dirancang sepenuhnya secara offline. Seluruh pencatatan dan kalkulasi dilakukan di komputer lokal Anda tanpa koneksi ke server eksternal mana pun.

Di mana data keuangan saya disimpan?

Data tersimpan di dalam file basis data SQLite bernama finance.db pada folder direktori kerja aplikasi. Anda dapat mencadangkan berkas ini kapan saja melalui menu Pengaturan > Backup Database.

Bagaimana jika saya ingin memindahkan data ke komputer baru?

Gunakan fitur Backup Database pada komputer lama, salin file cadangan yang dihasilkan, lalu gunakan fitur Restore Database pada aplikasi di komputer baru. Sistem akan melakukan validasi keabsahan struktur database sebelum memulihkan data.

Apakah aplikasi ini berbayar atau mengandung iklan?

Tidak ada biaya langganan, biaya lisensi, maupun iklan. Proyek ini bersifat gratis dan sumber terbuka untuk mendukung kebutuhan manajemen keuangan mahasiswa.
